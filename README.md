# ⚡ Basic Docker Commands

## Check Docker Version

```bash
docker --version
```

## Pull Docker Image

```bash
docker pull nginx
```

## Run Nginx Container

```bash
docker run -d -p 8080:80 nginx
```

## View Running Containers

```bash
docker ps
```
